## How to Run Locally

No installation needed. Just clone and open:

```bash
git clone https://github.com/sabairhussain/sabairhussain.github.io.git
cd sabairhussain.github.io
open index.html
```

Or simply visit the live URL above.

---

## Deploying via GitHub Pages

1. Ensure `index.html` is at the root of the `main` branch
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch → main → / (root)**
4. Site will be live at `https://sabairhussain.github.io`
